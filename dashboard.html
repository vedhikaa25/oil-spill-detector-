System Design

Model Architecture

U-Net encoder-decoder with ImageNet-pretrained ResNet34 backbone for pixel-level oil spill segmentation.

🔬

ResNet34 Encoder

Pre-trained on ImageNet with 34 residual layers. Extracts hierarchical visual features: edges → textures → object parts → scenes. Transfer learning gives a strong head-start.

🔄

U-Net Decoder

Symmetric upsampling path with skip connections that bridge encoder features to decoder layers, preserving fine spatial details critical for precise oil boundary delineation.

⚖️

BCE + Dice Loss

Combined loss handles class imbalance: BCE ensures per-pixel accuracy while Dice Loss specifically penalizes missed oil regions, preventing the model from ignoring small spills.

📐

512×512 Input

All images resized to 512×512 with ImageNet normalization (μ=[0.485, 0.456, 0.406], σ=[0.229, 0.224, 0.225]). Albumentations pipeline for augmentation during training.
